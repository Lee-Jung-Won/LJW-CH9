Multi Chatting
  Logic Flow
    1. Enter > BroadCast "Enter Player" to EveryOne
    2. Chatting With Inner Player
    3. Can Play Using "Baseball" Keyword ( Every In Player Participate Automatically without in Game Player )
    4. In Game, You Have 3 Chance to try, and Block your inputbox
    5. EveryPlayer in SameGame Have to use their TryChance ( Without input, Can Standby infinite > OtherPlayer will be sad )
    6. End Game, Broadcast Result to EveryOne include InGamePlayer, and Release All Block Input
    7. return Lobby and cycle
